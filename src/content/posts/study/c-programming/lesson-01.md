计算机的每一个操作都是根据人们事先指定的指令进行的。要让计算机执行一系列操作，必须事先编好一条条指令并输入计算机。所谓程序，就是一组计算机能识别和执行的指令：每一条指令让计算机执行特定的操作，一个特定的指令序列用来完成一定的功能。计算机的一切操作都由程序控制，离开程序，计算机一事无成。

## 一、从机器指令到 C 语言

计算机工作基于二进制，从根本上说，它只能识别和接受由 0 和 1 组成的指令。这种计算机能直接识别和接受的二进制代码称为**机器指令**，机器指令的集合就是该计算机的**机器语言**。机器语言与人们习惯的语言差别太大，难学、难写、难记、难检查、难修改，所以早期只有极少数计算机专业人员会写程序。

为了克服这些缺点，人们创造出**符号语言**：用一些英文字母和数字表示指令，例如用 ADD 代表"加"，SUB 代表"减"，JMP 代表"跳转"。上面那条加法指令可以写成

```
ADD AX,BX        ; 把寄存器 AX 与 BX 中的数相加，结果放回 AX
```

计算机并不能直接识别和执行符号语言的指令，需要用一种称为**汇编程序**的软件把它转换为机器指令，一般一条符号指令对应一条机器指令，这个转换过程称为"代真"或"汇编"，所以符号语言又叫**汇编语言**。汇编语言比机器语言好记一些，但仍然只在专业人员中使用。

机器语言和汇编语言都完全依赖具体机器，不同型号的计算机互不通用，用甲机器的语言写的程序在乙机器上不能用 —— 这类"贴近"计算机的语言称为**计算机低级语言**。

20 世纪 50 年代出现了第一个计算机**高级语言** FORTRAN。它很接近人们习惯使用的自然语言和数学语言：语句和运算符用英文单词与日常数学式子表示，结果用英文和数字输出。例如在 FORTRAN 中计算并输出 3.5×6sin(π/3)，只要写

```
PRINT *, 3.5 * 6 * SIN(3.1415926/3)
```

高级语言不依赖具体机器，用它写的程序对任何型号的计算机都适用（或只需很少修改），与具体机器距离较"远"。计算机同样不能直接识别高级语言程序，也要用**编译程序**把用高级语言写的**源程序**转换（编译）为机器指令的**目标程序**，再让计算机执行，最后得到结果；高级语言的一条语句往往对应多条机器指令。

C 语言是一种高级语言，也是一种用途广泛、功能强大、使用灵活的过程性（procedural）编程语言。它既可用于编写应用软件，又可用于编写系统软件。它是**结构化**的语言，支持结构化程序设计方法；C++、C#、Visual Basic 和 Java 等则支持面向对象的程序设计方法，本书不涉及。

C 语言的标准经历了几次修订：C89、C99、C11、C17、C23。要注意的是，**由不同软件公司提供的 C 语言编译系统未必能完全实现所有标准建议的功能** —— 例如开源的 GCC 实现了 C23 标准，而微软的 Visual C++ 2019 只支持 C99，同时提供支持 C11/C17 的加装模块。写程序之前，先弄清自己所用的编译系统支持到哪一版，不要用编译器不认的写法。

## 二、C 语言的特点

C 语言本身是一个很小的内核语言，只包括极少的与硬件有关的成分。它不直接提供输入和输出语句、有关文件操作的语句和动态内存管理的语句 —— 这些操作是由编译系统提供的**库函数**来实现的。语言简洁、紧凑，程序书写形式自由，主要用小写字母，压缩了一切不必要的成分，所以源程序短，输入程序时工作量少；相应地，C 的编译系统也相当简洁。

在表达能力上，C 的运算符范围很广，把括号、赋值和强制类型转换等都作为运算符处理，表达式类型多样化；数据类型也丰富，提供整型、浮点型、字符型、数组类型、指针类型、结构体类型和共用体类型，C99 又扩充了复数浮点类型、超长整型（long long）和布尔类型等。尤其是**指针类型**，使用灵活多样，可以用来实现链表、树等各种复杂的数据结构，这是 C 的一个重要特征。此外 C 具有结构化的控制语句（if…else、while、do…while、switch、for），并以函数作为程序的模块单位，便于实现程序的模块化 —— C 是完全模块化和结构化的语言。

对初学写程序的人，最需要留意的是这一条：**C 的语法限制不太严格，程序设计自由度大**。例如对数组下标越界不作检查，要由程序编写者自己保证程序的正确；对变量的类型使用也比较灵活，整型量与字符型数据以及逻辑型数据可以通用。一般的高级语言语法检查很严，几乎能查出所有语法错误，而 C 为了使编写者有较大的自由度放宽了检查。"限制"与"灵活"是一对矛盾：限制严格就失去灵活性，强调灵活就必然放松限制。**所以不要过分依赖 C 编译程序查错，必须自己仔细检查程序**；对于不熟练的人员，编写一个正确的 C 语言程序可能会比编写一个其他高级语言程序难一些。

在机器层面，C 允许直接访问物理地址，能进行位（bit）操作，能实现汇编语言的大部分功能，可以直接对硬件进行操作 —— 它既有高级语言的功能，又具有低级语言的许多功能，因此既是成功的系统描述语言，又是通用的程序设计语言。同时它的**可移植性**好：C 的编译系统相当简洁，很容易移植到新的系统；标准链接库是用可移植的 C 语言写的，在新系统上运行时可以直接编译标准链接库中的大部分功能，不需要修改源代码。加上生成的目标代码质量高、程序执行效率高，C 至今的主要用途之一是编写嵌入式系统程序，以及需要高速运行效率的系统功能和应用。

## 三、最简单的 C 程序

**例 1.1**　要求在屏幕上输出以下一行信息：`This is a C program.`

```c
#include <stdio.h>              //这是编译预处理指令
int main()                      //定义主函数
{                               //函数开始的标志
    printf("This is a C program.\n"); //输出所指定的一行信息
    return 0;                   //函数执行完毕时返回函数值0
}                               //函数结束的标志
```

运行结果就是在屏幕上输出 `This is a C program.`。

`main` 是函数的名字，表示"主函数"，**C 语言程序的执行总是从 main 函数开始的**。main 前面的 `int` 表示此函数的类型是 int 型（整型），执行主函数后会得到一个整数，或称函数的返回值为整型。`return 0;` 的作用是把整数 0 作为 main 函数的返回值并结束 main 函数的执行，返回到调用函数处。**每个 C 语言程序都必须有一个 main 函数**。函数体由花括号 `{}` 括起来，本例主函数内有两个语句。

`printf` 是 C 编译系统提供的函数库中的输出函数（详见第 4 章）。它双撇号内的字符串按原样输出；`\n` 是换行符，即在输出后把显示屏上的光标位置移到下一行的开头。每个语句最后都有一个分号，表示语句结束。

在使用函数库中的输入输出函数前，编译系统需要程序提供有关此函数的信息，第 1 行 `#include <stdio.h>` 的作用就是提供这些信息。stdio 是 standard input & output 的缩写，`.h` 表示**头文件**（header file），因为这些文件都放在程序各文件模块的开头。输入输出函数的相关信息已事先放在 stdio.h 文件中，`#include` 指令把这些信息调入供使用；没有这条指令，C 编译器就没有关于 printf 的信息，不可能执行 printf 函数。先记住一点即可：**程序中要用到标准函数库的输入输出函数，就必须在本文件模块的开头加下面一行**：

```c
#include <stdio.h>
```

**例 1.2**　求两个整数之和。

```c
#include <stdio.h>              //这是编译预处理指令
int main()                      //定义主函数
{                               //函数开始
    int a,b,sum;                //声明部分，定义 a,b,sum 为整型变量
    a = 123;                    //对变量a赋值
    b = 456;                    //对变量b赋值
    sum = a + b;                //进行a+b的运算，并把结果存放在变量sum中
    printf("sum is %d\n",sum);  //输出结果
    return 0;                   //使函数返回值为0
}                               //函数结束
```

程序第 4 行是**声明部分**，定义 a、b、sum 为整型（int）变量；接着为 a、b 赋值，再把和数存进 sum。输出语句 `printf("sum is %d\n",sum);` 的圆括号内有两部分：第一部分是双撇号中的 `sum is %d\n`，称为**输出格式字符串**，其中 `%d` 是指定的输出格式，表示以十进制整数形式输出；第二部分 sum 是要输出的变量。执行 printf 时，变量 sum 的值会取代双撇号中的 `%d`，所以屏幕上显示 `sum is 579`（123 与 456 之和），然后换行。

由于本程序正常运行和结束，main 函数的返回值应为 0。现在并没有去检查和利用这个函数值，但在某些时候会需要用到它。

**例 1.3**　求两个整数中的较大者。用一个函数来实现，在主函数中调用此函数并输出结果。

```c
#include <stdio.h>
//主函数
int main()
{                               //主函数开始
    int max(int x,int y);       //对被调用函数max的声明
    int a,b,c;                  //定义变量a,b,c
    scanf("%d,%d",&a,&b);       //输入变量a和b的值
    c = max(a,b);               //调用max函数，将得到的值赋给c
    printf("max=%d\n",c);       //输出c的值
    return 0;                   //返回函数值0
}                               //主函数体结束

//求两个整数中的较大者的max函数
int max(int x,int y)            //定义max函数，函数值为整型，形式参数x和y为整型
{
    int z;                      //max函数中的声明部分，定义本函数中用到的变量z为整型
    if(x>y) z=x;                //若x>y成立，将x的值赋给变量z
    else z=y;                   //否则，将y的值赋给变量z
    return(z);                  //将z的值作为max函数值，返回到调用max函数的位置
}
```

运行时从键盘输入 `8,5`，程序输出 `max=8`。

本程序包括两个函数：主函数 main 和被调用的函数 max。max 函数的作用是把 x 和 y 中较大者的值赋给变量 z，`return` 语句把 z 的值作为 max 的函数值带回 main 函数中调用它的地方 —— 返回值是通过函数名 max 带回到调用处的。

程序第 5 行是对被调用函数 max 的**声明**（declaration）。为什么需要它？因为在主函数中要调用 max，而 max 函数的定义却在 main 函数之后，编译是自上而下进行的，编译到调用那一行时编译系统还不知道 max 是什么，无法把它作为函数调用处理，所以要先声明，告诉编译系统 max 是什么以及它的有关信息。有关函数的声明详见第 7 章。

第 7 行的 `scanf` 是输入函数，它圆括号内也有两部分：双撇号中的 `"%d"` 指定输入的数据以十进制整数形式输入，后面的 a 和 b 指定数据放到哪里。a 和 b 前面各有一个 `&`，在 C 中 `&` 是**地址符**，`&a` 的含义是"变量 a 的地址"，`&b` 是"变量 b 的地址"。执行 scanf 时，从键盘读入的两个整数被放到变量 a 和 b 的地址，从而分别赋给 a 和 b。

第 8 行以 `max(a,b)` 的形式调用 max 函数，调用时把 a 和 b 作为**实际参数**的值分别传送给 max 函数中的**形式参数** x 和 y，然后执行 max 的函数体，使 z 得到两者中的较大值，`return(z)` 把 z 带回 `=` 的右侧取代 `max(a,b)`，再赋给变量 c。

**本例两个函数都有 return 语句，请注意异同**：两个函数都定义为整型，都有函数值，都需要用 return 指定返回值；但 main 中的 return 指定的返回值一般为 0，用于表示整个程序顺利执行，而 max 的返回值是求出的最大值 z，只有通过 return 才能把 z 作为函数值返回调用它的 main 函数中。不要以为在 max 中求出最大值后它就会自动作为函数值返回，必须用 return 语句指定将哪个值作为函数值；也不要**不加分析地在所有函数的最后都写上 `return 0;`**。

### 从这三个例子看 C 程序的组成

一个程序由一个或多个源程序文件组成。规模较小的程序往往只包括一个源程序文件：例 1.1 和例 1.2 在同一个文件里只有一个 main 函数，例 1.3 在同一个文件里有两个函数。在一个源程序文件中可以包括三部分：**预处理指令**（如 `#include <stdio.h>`，编译系统在正式编译前先由预处理器处理，例如把 stdio.h 的内容读进来取代这条指令）、**全局声明**（在函数之外进行的数据声明，在函数外面声明的变量称为全局变量；在函数中声明的是局部变量，只在函数范围内有效）、**函数定义**。

**函数是 C 程序的主要组成部分**，程序的几乎全部工作都是由各个函数分别完成的，编写 C 程序的工作主要就是编写一个个函数。一个 C 语言程序由一个或多个函数组成，其中**必须包含一个 main 函数，且只能有一个**。小程序只包含一个源程序文件，其中含若干函数；程序规模较大时，可以把一个程序分成若干源程序文件（一个源程序文件就是一个程序模块），分别编译得到相应的目标程序后，再把它们连接成一个统一的二进制的可执行程序。被调用的函数可以是系统提供的**库函数**（如 printf 和 scanf），也可以是用户自己编制的函数（如例 1.3 的 max）。C 的函数库很丰富，ANSI C 建议提供一百多个标准库函数，不同编译系统还各自增加了一些库函数，个数和功能不完全相同。

一个函数包括两部分。**函数首部**即函数的第 1 行，包括函数名、函数类型、函数属性、函数参数（形式参数）名、参数类型，例如 `int max (int x, int y)`。函数名后面必须跟一对圆括号，括号内写参数名及其类型；没有参数时可以在括号中写 void，也可以是空括号，例如 `int main(void)` 或 `int main()`。**函数体**即函数首部下面花括号内的部分，一般包括**声明部分**（定义本函数中用到的变量、对本函数所调用的函数进行声明）和**执行部分**（由若干语句组成）。某些情况下可以没有声明部分（如例 1.1），甚至可以既无声明部分也无执行部分，例如

```c
void dump()
{}
```

是一个什么也不做的空函数，但这是合法的。

**程序总是从 main 函数开始执行的，而不论 main 函数在整个程序中的位置如何**（可以放在最前头，也可以放在最后，或在一些函数之前、另一些函数之后）。程序中要求计算机完成的操作由 C 语句完成；C 程序书写格式比较自由，一行内可以写几个语句，一个语句也可以分写在多行上，但为清晰起见习惯上每行只写一个语句。**在每个数据声明和语句的最后必须有一个分号**，分号是 C 语句的必要组成部分。还有一点要记住：**C 语言本身不提供输入输出语句**，输入和输出操作是由库函数 scanf 和 printf 等完成的，C 对输入输出实行"函数化" —— 这样 C 本身的规模较小，编译程序简单，容易在各种机器上实现，程序具有可移植性。

## 四、注释

在程序各行的右侧如果有 `//`，表示从此处到本行末是**注释**，用来对程序有关部分进行说明。写 C 程序时用注释可以方便自己和别人理解程序各部分的作用。程序进行编译处理时，每个注释被替换为一个空格，因此注释部分**不产生目标代码**，对运行不起作用 —— 注释只是给人看的，不是让计算机执行的。

C 语言允许两种注释方式。一种是以 `//` 开始的**单行注释**：从 C99 开始支持，是现在更流行的用法；它既可以单独占一行，也可以出现在一行中其他内容的右侧；范围从 `//` 开始，以换行符结束，**不能跨行**，一行写不下时可以在下一行重新用 `//` 继续写。另一种是以 `/*` 开始、以 `*/` 结束的**块式注释**：从 C 语言之初就支持，可以包含多行内容，编译系统发现 `/*` 后会开始找 `*/`，把二者之间的内容作为注释。

注意在字符串中的 `//` 和 `/*` 都不作为注释的开始，而是作为字符串的一部分，例如

```c
printf("//how do you do!\n");
printf("/* how do you do! */\n");
```

输出的分别是 `//how do you do!` 和 `/* how do you do! */`。

如果所用的是中文 C 编译系统，注释可以用汉字或英文字符表示。C89 及之前只允许用 `/* … */` 形式的注释，因为 C++ 允许 `//` 形式的注释，`//` 注释也被称为"C++风格"的注释；C99 正式将它纳入 C 语言新标准，目前常用的编译系统（Visual C++、Turbo C++、GCC 等）都支持。

## 五、从源程序到可执行程序

计算机不能直接识别和执行用 C 写的指令，必须用编译程序把 C 源程序翻译成二进制形式的目标程序，再把该目标程序与系统的函数库以及其他目标程序连接起来，形成可执行的目标程序。在编写好一个 C 源程序后，上机一般要经过以下几个步骤。

**输入和编辑程序。** 通过键盘向计算机输入程序，发现错误及时改正，最后将源程序以文件形式存放在指定的文件夹内，文件用 `.c` 作为后缀，例如 `f.c`。

**对源程序进行编译。** 先用编译系统提供的预处理器对源程序中的预处理指令进行预处理，例如对于 `#include <stdio.h>` 就是把 stdio.h 的内容读进来取代它，由预处理得到的信息与程序其他部分一起组成一个完整的、可以用来正式编译的源程序，然后由编译系统进行编译。编译首先对源程序进行检查，判定有无语法方面的错误，如有则发出"出错信息"，修改后重新编译，如此反复直到没有语法错误为止；这时编译程序自动把源程序转换为二进制形式的目标程序（在 Visual C++ 中后缀为 `.obj`，如 `f.obj`）。在用编译系统对源程序进行编译时，自动包括了预编译和正式编译两个阶段，一气呵成，用户不必分别发出两次指令。

**进行连接处理。** 编译得到的目标文件还不能供计算机直接执行。一个程序可能包含若干源程序文件，而编译是以源程序文件为对象的，一次编译只能得到与一个源程序文件相对应的目标模块，它只是整个程序的一部分。必须把所有的目标模块连接装配起来，再与函数库连接成一个整体，生成可供计算机执行的**可执行程序**（在 Visual C++ 中后缀为 `.exe`，如 `f.exe`）。即使一个程序只包含一个源程序文件，编译后得到的目标程序也不能直接运行，也要经过连接阶段，因为要与函数库连接才能生成可执行程序。以上连接工作由编译系统中的"连接编辑程序"实现。

**运行可执行程序，得到运行结果。**

一个程序从编写到运行得到预期结果，并不是一次就能成功的，往往要经过多次反复。除了用人工方式检查外，还须借助编译系统检查有无语法错误。有时编译过程未发现错误，能生成可执行程序，但运行的结果不正确 —— 一般情况下这不是语法方面的错误，而可能是程序**逻辑**方面的错误，例如计算公式不正确、赋值不正确等，应当返回检查源程序并改正。目前使用的很多 C 编译系统都是**集成开发环境**（IDE），把程序的编辑、编译、连接和运行等操作集中在一个界面上进行。不应当只会使用一种编译系统，无论用哪一种，都应当能举一反三，需要时会用其他编译系统工作。

## 六、程序设计的任务

程序设计是指从确定任务到得到结果、写出文档的全过程，一般经历以下几个工作阶段。

**问题分析。** 对任务认真分析，研究所给定的条件，分析最后应达到的目标，找出解决问题的规律，选择解题的方法。在此过程中可以忽略一些次要因素使问题抽象化，例如用数学式子表示问题的内在特性，这就是建立模型。

**设计算法。** 即设计出解题的方法和具体步骤。例如要解一个方程式，就要选择用什么方法求解，并把求解的每一个步骤清晰无误地写出来，一般用流程图来表示解题的步骤。

**编写程序。** 根据得到的算法，用一种高级语言编写出源程序。

**编辑、编译和连接，得到可执行程序。**

**运行程序，分析结果。** 运行可执行程序得到运行结果，但**能得到运行结果并不意味着程序正确**，要对结果进行分析，看它是否合理。例如把 `b=a;` 错写为 `a=b;`，程序不存在语法错误，能通过编译，但运行结果显然与预期不符。因此要对程序进行调试（debug）—— 程序调试就是找到程序当中的错误并改正错误，程序设计者必须善于发现和改正程序中的错误。

## 术语解释

**程序与语言**

- **指令**：命令计算机做一次具体操作的信号。**机器指令**是计算机能直接识别的那种，由一串 0 和 1 组成。
- **机器语言**：一台计算机的全部机器指令的集合。不同型号的计算机机器语言互不通用。
- **符号语言（汇编语言）**：用 ADD、SUB 这类英文缩写代替 0 和 1 写指令的语言，靠**汇编程序**翻译成机器指令，这个翻译过程叫**代真**或**汇编**。
- **低级语言**：机器语言与汇编语言的合称，特点是贴近机器、依赖具体机型。
- **高级语言**：接近自然语言和数学式子的语言，不依赖具体机器，C 就是高级语言。
- **源程序 / 目标程序**：用高级语言写的程序叫源程序；翻译成机器指令后的程序叫目标程序。源程序相当于原稿，目标程序相当于译稿。
- **编译程序（编译器）**：把源程序翻译成目标程序的软件。
- **过程性语言**：写程序时要一步步指定"先做什么、再做什么"的语言，C 属于这一类；**面向对象的语言**（C++、Java 等）则以"对象"为单位组织程序。
- **结构化程序设计**：要求程序只由顺序、选择、循环三种基本结构组成，流程不随意跳转，便于阅读和维护。C 支持这种方法。
- **编译系统**：编写、编译、连接、运行 C 程序所需的一整套软件。
- **库函数**：编译系统事先写好、可以直接拿来调用的函数，如 printf、scanf。C 语言本身不带输入输出，这些活全靠库函数干。
- **寄存器**：CPU 内部用来临时存放数据的小格子，如 `ADD AX,BX` 里的 AX、BX。

**C 程序的零件**

- **main 函数（主函数）**：每个 C 程序有且只有一个，程序总是从它开始执行。
- **函数首部 / 函数体**：首部是函数的第一行，写函数名、类型和参数；函数体是首部下面花括号内的部分。
- **声明部分 / 执行部分**：函数体里，前面用来定义变量、声明被调用函数的部分叫声明部分，后面真正干活的一串语句叫执行部分。
- **返回值**：函数执行完交回给调用处的值。main 的返回值一般为 0，表示程序顺利结束。
- **声明（declaration）**：告诉编译系统某个名字是什么、有哪些信息。例如 `int max(int x,int y);` 就是对 max 函数的声明 —— 因为 max 的定义写在 main 后面，不先声明，编译到调用那一行时编译系统不认识它。
- **赋值**：用 `=` 把右边的值送进左边的变量。`=` 在这里叫**赋值运算符**，不是数学里的"等于"。
- **全局变量 / 局部变量**：在函数外面声明的变量叫全局变量，在函数内部声明的叫局部变量，后者只在函数范围内有效。
- **空函数**：函数体里什么也没有的函数，如 `void dump() {}`，合法但什么也不做。
- **模块**：一个源程序文件可以看作一个程序模块。程序大时拆成多个模块，分别编译后再连接起来。

**输入输出与格式**

- **头文件（.h）**：存放函数声明、宏定义等信息的文件，如 stdio.h。`.h` 是 header file 的缩写，这类文件都放在程序文件模块的开头。
- **预处理指令 / 预处理器**：以 `#` 开头的指令叫预处理指令，在正式编译之前先由预处理器处理。`#include <stdio.h>` 的作用就是把 stdio.h 的内容读进来，取代这一行。
- **格式字符串**：printf 或 scanf 双撇号里规定输出、输入格式的那部分，如 `"sum is %d\n"`。
- **`%d`**：格式说明，表示"以十进制整数形式"输出或输入。
- **`\n`**：换行符，让显示屏上的光标移到下一行的开头。
- **地址符 `&`**：放在变量前面，表示"这个变量的地址"。scanf 需要知道数据该放到哪里，所以要写 `&a`、`&b`。
- **形式参数 / 实际参数**：函数定义时括号里的变量（如 max 的 x、y）是形式参数；调用时真正传进去的值（如 a、b）是实际参数。

**注释**

- **注释**：写在程序里给人看的说明。编译时每个注释被替换成一个空格，不产生目标代码，对运行不起作用。

**从源程序到可执行程序**

- **预处理**：编译之前的第一道工序，处理 `#include`、`#define` 这类指令。
- **编译**：把源程序翻译成二进制目标程序，同时检查有无语法错误。
- **目标文件（.obj）**：编译产出的二进制文件，还不能直接运行。
- **连接**：把编译得到的一个个目标模块与库函数连接装配成一个整体，做这件事的程序叫**连接编辑程序**。
- **可执行程序（.exe）**：连接之后生成的、可以直接运行的程序。
- **集成开发环境（IDE）**：把编辑、编译、连接、运行集中在一个界面上的软件。
- **语法错误 / 逻辑错误**：不符合语法规则的错误，编译时就会报出来；语法没错但结果不对，属于逻辑错误，例如把 `b=a;` 写成 `a=b;`。
- **调试（debug）**：找出程序中的错误并改正的过程。
- **可移植性**：程序换一台机器、换一个系统还能用的性质。C 的可移植性好，因为标准链接库也是用可移植的 C 写的。
- **目标代码**：编译产出、交给机器执行的代码；它质量高、执行效率高是 C 的优点之一。

**数据类型与其他**

- **关键字**：C 语言规定好用途、不能拿来当变量名的单词，如 int、if、return。
- **运算符 / 表达式**：运算符是做运算的符号（+、-、=、括号等）；由运算符和运算对象组成的式子叫表达式。
- **数据类型**：规定一个数据属于哪一类、占多大地方。**整型**（int）存整数，**浮点型**存小数，**字符型**存单个字符。
- **数组**：一组同类型数据排成一列存放的形式。
- **指针**：专门用来存放地址的数据类型，用它可以实现链表、树这类复杂结构。
- **结构体 / 共用体**：把几个不同类型的数据打包在一起的自定义类型。
- **控制语句**：控制程序走向的语句，包括 if…else（选择）、while / do…while / for（循环）、switch（多分支）。
- **位（bit）操作**：直接对二进制位进行的运算。
- **物理地址**：内存或硬件中某个具体位置的编号。C 允许直接访问它，所以能用来编写系统软件。
- **嵌入式系统**：装在家电、汽车、仪器等设备里、专门完成某项控制任务的计算机系统，是 C 目前的主要用途之一。

**程序设计流程**

- **建立模型**：把实际问题去掉次要因素，用数学式子等方式表示出来。
- **算法**：解题的方法和具体步骤，一般用**流程图**画出来。
- **程序设计**：从确定任务到得到结果、写出文档的全过程 —— 问题分析、设计算法、编写程序、编辑编译连接、运行并分析结果。
