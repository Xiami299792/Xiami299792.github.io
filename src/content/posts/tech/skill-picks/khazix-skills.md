**一句话**：数字生命卡兹克把自己每天在用的 6 个技能开源出来的合集——"都是在项目里跑通了一段时间才搬出来"。

**里面有什么**：

| 技能 | 干什么 |
| --- | --- |
| `leader`（领导） | 把一句模糊想法定义成清晰目标，让 Agent 自己跑几小时到完成 |
| `storage-analyzer`（清理垃圾） | 一句话扫全机磁盘，三色分级给清理决策 |
| `aihot`（AI HOT） | 一句话拿到 AI HOT 日报与动态，无需 API Key |
| `neat-freak`（洁癖） | 干完活跑 `/neat`，对齐项目文档、CLAUDE.md 与 Agent 记忆 |
| `hv-analysis`（横纵分析法） | 丢进一个产品/公司/概念，产出一份万字研究报告 |
| `khazix-writer`（卡兹克写作） | 用作者本人的口吻和节奏写公众号长文 |

遵循 Agent Skills 开放标准，Claude Code、Codex、Cursor 等 40+ Agent 都能装。
