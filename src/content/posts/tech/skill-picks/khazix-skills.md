这一篇不是单个技能，是一份**合集**：公众号「数字生命卡兹克」把自己每天在用的几个技能开源了。作者的话很实在——"都是在项目里跑通了一段时间，确实省事，才搬出来开源的，没什么花活"。

## 里面有什么

| 技能 | 干什么 |
| --- | --- |
| `leader`（领导） | 把一句模糊的想法定义成一个清晰的**目标**，让 AI 拿着自己跑几个小时到完成 |
| `storage-analyzer`（清理垃圾） | 一句话扫描 Mac / Windows 整机磁盘，三色分级给清理决策 |
| `aihot`（AI HOT 资讯） | 让 Agent 一句话拿到 AI HOT 日报和全部 AI 动态，不用 API Key |
| `neat-freak`（洁癖） | 干完活跑一下 `/neat`，自动对齐项目文档、CLAUDE.md 和 Agent 记忆 |
| `hv-analysis`（横纵分析法） | 想搞懂一个产品/公司/概念，丢给它，产出一份万字 PDF 研究报告 |
| `khazix-writer`（卡兹克写作） | 装上之后，Agent 用他的口吻和节奏写公众号长文 |

## 我最想推荐的是 leader

不是因为功能多，而是因为它把"**怎么给 AI 交代一件事**"写成了七个问题。这套问法本身比技能值钱，抄下来用在别处也行：

| # | 问题 | 落到任务书里是什么 |
| --- | --- | --- |
| 1 | **目的** | 遇到没写到的岔路口，靠这句自己判断 |
| 2 | **完成态** | 具体到"靠岸那一刻机器就能判"，而不是"出去转一圈" |
| 3 | **证据** | 每条验收都要贴出实际命令输出，不能船长说满载就是满载 |
| 4 | **反作弊** | 把偷懒路径一条条点名禁止（比如"把测试删了让绿色通过"） |
| 5 | **地界** | 白名单 + 跑满 N 轮即停 |
| 6 | **取舍** | 明确"算得对 > 做得全 > 做得快" |
| 7 | **未知** | 拿不准的写进待裁决清单，跳过做别的，别硬闯也别抛锚 |

## 怎么装

在支持 Agent Skills 的工具里直接说一句，让它自己 clone：

```text
帮我安装这个 skill：https://github.com/KKKKhazix/khazix-skills/tree/main/<skill-name>
```

把 `<skill-name>` 换成 `leader`、`neat-freak`、`hv-analysis` 之类。**如果你的工具不支持 Skill 也没关系**：把那个目录的 `SKILL.md` 全文下载下来，当项目规则文件用（或直接贴进对话），效果一样。

## 什么时候别用

- 别一次全装：技能列表越长，Agent 每次选择越费劲，先挑一个真需要的
- `storage-analyzer` 涉及删文件，第一次用先看清楚它的分级规则再动手
- `khazix-writer` 是**模仿特定作者口吻**的工具，别拿它写需要你自己署名的正式材料
