本章要解决的问题：你以后会反复听到三个词——DSH、API、Agent。这一章把这三个词讲清楚，再简述若干个常用词。

这一章没有需要操作的部分，读完就行。

## 1.1 DSH 是什么

这本书里说的「DSH」，指的是你要安装的那个桌面程序（全名 DSH Desktop）。它长着一个普通程序的样子，双击图标就能打开。第 2 章带你装上它。

但还有另一个东西也叫 DSH——DeepSeek Harness。它是这个桌面程序内部真正在干活的那套系统，由 DeepSeek 官方开发。你在本书里只会在第 2.1.8 节遇到它。

一句话记住：DSH Desktop 是外壳，DeepSeek Harness 是里面那台机器。本书说「DSH」，默认指前者。

1. DSH 是一个装在你电脑上的 AI 工作台。
2. 网页版 AI 只能把答案显示在屏幕上；DSH 能直接读你电脑里的文件、改文件、运行命令。
3. 因为它能动手，所以它比网页版有用得多，也更容易出事。

你用网页版 AI 的时候，流程是这样的：你把文件上传上去，它读完，把结果打在屏幕上，然后你自己复制、粘贴、保存、改名、放到该放的文件夹里。它只负责想，动手的是你。

用 DSH 的时候，流程变了。你说「把这份 PDF 里的题目整理成一个表格文件，存到题目文件夹里」，它自己去读那份 PDF、自己生成表格文件、自己存到指定位置。你要做的只是最后检查一下对不对。

它负责想，也负责动手。

因为能动手，所以第 3 章会教你把它的活动范围限制在一个文件夹里；因为它会出错，所以每一章都有验收环节，让你确认它做的是不是你要的。

DSH 还在快速更新。 版本号里带 `rc` 表示还在测试阶段——功能会变、界面会变，教程和实际界面对不上是常有的事。本书核对的是 `0.1.5-rc.1`（2026-09）。

打开 DSH 之后，你会看到一个对话输入框，以及设置、工作区、插件等几个入口。具体位置随版本变化，第 3 章会带你逐个找到它们。

## 1.2 API 和 Key 是什么

DSH 本身不包含那个负责「思考」的 AI。它更像一个空的工作台，需要接上一个真正的模型才能干活。

API 是程序之间说话的通道。DSH 通过这条通道把你说的话送给模型，再把模型的回答拿回来。

Key 是走这条通道的凭证，是一长串字符。有了它，模型那边才知道这次请求是谁发的、该记在谁账上。

所以你要做的第一件事，是去模型提供商那里申请一个 Key，然后填进 DSH。这件事会在第 3 章做，这里先记住两件必须知道的事。

### 第一件：它按使用量扣费

不是包月，是用多少扣多少。你发给它的每个字、它答给你的每个字，都算在里面。

单次很便宜，便宜到你不会注意到。但它是累积的：一份长文档读十遍、同一个问题问二十遍、来回改三十轮，都会推高费用。

具体怎么控制，第 7.3 节会讲。现在先建立一个意识：它花钱，而且花在你不太看得见的地方。

### 第二件：Key 只在创建时完整显示一次

申请 Key 的时候，页面会把它完整显示出来。关掉页面之后，你就再也看不到完整内容了，只能看到开头几位。丢了只能删掉重建一个。

所以拿到的那一刻就要立刻复制保存。

存在哪里： 密码管理器，或者你自己电脑上的一个文本文件。

不要存在哪里： 不要发到微信、QQ 群，不要贴在论坛或笔记网站上，不要写进任何要发给别人的文件里。Key 泄露之后的直接后果是别人用你的额度，账单算在你头上。

本书所有示例中的 Key 都写作 `你的密钥`，那是占位符。你自己的 Key 不要写进任何练习文件、也不要发给别人。

## 1.3 Agent 是什么

Agent 是能自己调用工具、分多步把任务做完的 AI。

|  | 普通对话 AI | Agent |
|---|---|---|
| 你给它什么 | 一个问题 | 一件事 |
| 它做什么 | 输出一段文字 | 拆步骤、找文件、改文件、运行命令、检查结果 |
| 你拿到什么 | 需要你自己照做的文字 | 已经做完的事，等你验收 |

会「动手」，是它和只会聊天的 AI 最根本的区别。

### 它做一件事的完整过程

理解这个过程，你就不会在它「一步一步来」的时候以为它卡住了。

1. 你告诉它要做的事。比如「把 `资料` 文件夹里的 PDF 变成一份笔记」。
2. 它把你的事拆成几步：先看看文件夹里有什么、再读 PDF、再整理、再写成文件。
3. 它开始执行。每执行一步，它会调用一个工具——读文件、写文件、运行命令、搜索。
4. 每调用完一个工具，它看结果，再决定下一步做什么。它能自己纠错：比如第一次读文件失败，它会换个方式再试。
5. 做完了，它告诉你结果。有时候它会中途停下来问你一件事。

第 5 步里「中途停下来问你」，就是审批。它要做有影响的操作（改文件、删文件、运行命令）之前会征求你的同意。这不是卡住了，也不是报错，是它在守规矩。 第 3.4 节会详细说怎么回答它。

## 1.4 十一个常用词

下面这些词，本书后面会直接用，不再解释。每个词给一行说明，看完有个印象就行，不用背——用到了再回来查也可以。（操作类的词比如终端、端口、PATH，在附录 B 有另一张卡。）

### 描述它怎么工作（4 个）

| 词 | 一行说明 |
|---|---|
| 会话 | 一段连续的对话。新开一个会话，它就不知道之前说过什么。 |
| 上下文 | 它当前「看得见」的全部内容，包括你说的话、它答的话、它读过的文件。有长度上限。 |
| 工具调用 | 它执行一个动作，比如读文件、写文件、运行命令。不是打字，是真的做。 |
| 任务 | 你交给它的一件事。一件事里可能包含很多次工具调用。 |

### 描述它的能力（2 个）

| 词 | 一行说明 |
|---|---|
| 技能（skill） | 一份写给 AI 看的操作说明，告诉它某类事情应该一步步怎么做。第 4 章会专门讲。 |
| 子代理 | 它临时叫来的另一个 AI，独立去干一件事，干完把结果交回来。第 5 章会用到。 |

### 描述配置与安全（5 个）

| 词 | 一行说明 |
|---|---|
| 工作区 | 它被允许改文件的那个文件夹。这个文件夹以外的文件它改不了。注意：读和联网不受这道边界限制。 |
| 权限 | 允许它做到什么程度。分三档：只读、工作区可写、完全访问。 |
| 审批 | 它做有影响的操作前，弹出来问你同不同意。 |
| 模型 | 真正负责思考的那个 AI。 |
| 提供商 | 提供模型的机构。 |

「工作区」和「权限」这两个词，是第 3 章的重点。你把这两个设对了，用起来基本不会出大问题。

## 本章验收

这一章没有操作，验收就是回答三个问题。能答上来，就可以进第 2 章了。

1. DSH 和网页版 AI，最主要的区别是什么？

参考：DSH 能直接读写你电脑上的文件、运行命令，网页版只能把文字显示在屏幕上。

2. 你的 Key 丢了能不能再看到？

参考：不能。它只在创建时完整显示一次，丢了只能重建。

3. 它做一件事做到一半弹出窗口问你，是出错了吗？

参考：不是。那是审批，是它在征求你的同意。

答不上来也没关系，翻回去看一眼对应的小节，用不了几分钟。

验收：上面三个问题都能用自己的话说出来（不要求背原句）。
