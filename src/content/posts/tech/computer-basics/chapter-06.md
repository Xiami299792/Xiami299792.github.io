**本章要点**

- 掌握十余个高频快捷键，使常用操作无须查找菜单。

## 6.2 剪贴板与任务管理器

剪贴板是不可见的暂存区域，Ctrl+C 复制的内容先存放于此，再由 Ctrl+V 取出，但它只能保留最后一次复制的内容。

剪贴板历史解决了这一问题：按 Win+V 打开，可查看最近复制的 25 条内容，单击其中一条即可粘贴。该功能默认关闭，首次按 Win+V 时任务栏一侧会弹出提示询问是否开启，选择「打开」即可；没开启时被覆盖的内容找不回来。

刚复制的内容被后续复制覆盖，这种情况在实际使用中较为常见，按 Win+V 即可将其找回。

任务管理器是初学者最应优先掌握的工具之一，快捷键为 Ctrl+Shift+Esc。

**表 6-4　任务管理器的三个用途**

| 操作目的 | 方法 |
|---|---|
| 关闭无响应的程序 | 在「进程」中找到该程序，右键单击并选择「结束任务」 |
| 缩短开机时间 | 在「启动应用」页中对不常用的程序右键单击并选择「禁用」 |
| 确定系统响应迟缓的原因 | 在「进程」中按 CPU 或内存排序，占用最高的进程即为原因 |

> **注意**　结束任务时不要关闭「Windows 资源管理器」，否则桌面与任务栏会消失。若已误关，可按 Ctrl+Shift+Esc 重新打开任务管理器，选择「运行新任务」，输入 explorer 后回车即可恢复。

## 6.3 其他系统自带工具

系统自带工具的共性优势是：无需安装、启动快、不附带广告。

**表 6-5　常用的系统自带工具**

| 工具 | 作用 | 打开方式 |
|---|---|---|
| 计算器 | 计算，支持键盘输入和单位换算 | 在搜索框中输入「计算器」 |
| 屏幕键盘 | 物理键盘失灵时可用鼠标单击输入 | Win+Ctrl+O |
| 记事本 | 记录纯文字，也可用于编写简单的批处理脚本 | 右键新建文本文档 |
| 画图 | 旋转、裁剪、加箭头标注；Windows 11 还支持一键去除背景 | 右键图片 → 打开方式 → 画图 |

记事本有一项进阶用法：将代码粘贴进去并保存，再把扩展名由 .txt 改为 .bat，该文件即成为可双击运行的小程序。不应运行他人发来的 .bat 文件，脚本可以删除文件、修改设置和访问网络，权限与普通程序相同。

## 6.4 关掉系统自带的推荐内容

新电脑开机后即出现广告，它们来自 Windows 自带的推荐位，并非病毒，可以逐个关闭。

**表 6-6　系统推荐内容的关闭位置**

| 位置 | 关闭方法 |
|---|---|
| 锁屏界面 | 设置 → 个性化 → 锁屏界面，背景改为「图片」，关掉「在锁屏界面上获取花絮、提示、技巧和更多内容」 |
| 桌面右下角「了解此图片」 | 设置 → 个性化 → 背景，把背景从「Windows 聚焦」改成「图片」或「纯色」 |
| 开始菜单搜索推荐 | 设置 → 隐私和安全性 → 搜索权限 →「更多设置」，关闭「显示搜索要点」 |
| Edge 新标签页 | 打开 Edge，单击右上角齿轮，关闭「快速链接」「网站导航」「显示内容」 |
| 任务栏多余元素 | 右键单击任务栏空白处 → 任务栏设置，隐藏「搜索」，关闭「任务视图」与「小组件」 |
