**本章要点**

- 掌握故障排查的四步法，明确常见症状的首查项。
- 掌握若干高频症状对应的处理办法。
- 了解校内电脑诊所的位置、值班时间与预约方式。
- 能按模板描述问题，使他人可以直接判断。

## 14.1 故障排查四步法

电脑出现问题时，应先查明具体情况，不要急于搜索「一键修复」。按下列四步操作。

第一步，复现并记录。记录故障开始时间、此前的操作以及报错的原文。应先截图，报错信息往往在操作慌乱时消失。

第二步，缩小范围。依次更换设备、账号、网络与文件进行测试；问题随哪一因素出现，即说明原因在该因素。同一网页在手机上可以打开而在这台电脑上打不开，问题在电脑或网络；更换其他文件可以打开而仅此文件打不开，问题在该文件本身。

第三步，查证。将报错原文加上英文双引号进行搜索，优先查看官方文档、微软社区与技术论坛的回答。出现「一键修复工具」「立即下载」一类链接时一律跳过。

第四步，动手处理。每次只改变一个变量，改动前先备份或创建还原点。同时修改三项设置，出现问题时将无法判断由哪一项引起。

## 14.2 常见症状速查

**表 14-1　常见症状与第一步该做的事**

| 症状 | 首先检查 |
|---|---|
| 电脑响应迟缓 | 按 Ctrl+Shift+Esc，查看占用 CPU 与内存最高的进程 |
| 开机时间延长 | 在任务管理器中禁用多余的启动项 |
| 蓝屏 | 记录错误码，回想近期安装的驱动或软件 |
| 可以登录 QQ 但网页无法打开 | 修改 DNS，或执行一次网络重置 |
| 文件误删 | 先按 Ctrl+Z，再检查回收站，最后右键文件 →「属性」→「以前的版本」选项卡（前提是系统保护或文件历史记录已开启，否则这一页是空的） |
| C 盘变红 | 按 13.1 节的顺序：软件缓存、磁盘清理、存储感知 |
| 无声音输出 | 先检查输出设备是否选择正确，再检查声卡驱动 |
| 摄像头无法打开 | 在设置中搜索「隐私」，检查相机权限 |
| 屏幕短暂黑屏后恢复 | 显卡驱动崩溃后自动重启，可考虑更新驱动 |
| 打印机无响应 | 先检查打印机电源与纸张，再按 Win+R 输入 services.msc，找到 Print Spooler 一项右键重新启动 |
| 发热严重 | 检查出风口是否被遮挡，考虑清灰与更换硅脂 |

蓝屏需要单独说明。蓝屏界面会显示停止代码，例如 IRQL_NOT_LESS_OR_EQUAL。应拍照或截图记录，再以该代码检索，可以定位到大致类别。多数蓝屏由驱动或内存引起，可回想近期安装的软件并尝试卸载。

如无法进入桌面，按 1.5 节所述的步骤进入安全模式。

## 14.3 电脑诊所

电脑诊所由网络开拓者协会的电脑诊所部门运营。电脑无法联网、系统出现故障、需要清灰换硅脂、需要加装硬盘或内存，一切软硬件问题都可以交由电脑诊所处理。

**表 14-2　诊所服务说明**

| 项目 | 说明 |
|---|---|
| 值班时间 | 每周一至周五 18:30 到 21:00 |
| 预约方式 | i 北理 → 电脑义诊 |
| 收费 | 仅收取配件成本费，不另收服务费 |
| 适合的问题 | 连不上网、系统故障、清灰换硅脂、加装硬盘内存 |

诊所设有多个地点，前往之前应先确认当天开放的地点。

**表 14-3　诊所地点**

| 地点 | 位置 | 说明 |
|---|---|---|
| 图书馆诊所 | 徐特立图书馆三楼自然科学第二阅览室最内侧，玻璃上贴有诊所字样的研讨室 | 进入图书馆需刷校园卡，室内请保持安静 |
| 求是社区诊所 | 求是书院社区（疏桐 D 地下室）最内侧右侧 | 进社区需刷校园卡；开放情况以 i 北理通知为准 |
| 办公室 | 北校区北理桥下，最靠近校门的房间 | 仅办理高风险业务 |

> **提示**　前往诊所应携带充电器，许多故障需要接通电源才能复现。各地点开放情况可能调整，出发前请在 i 北理上确认。

## 14.4 提问的方法

并非所有问题都需要前往诊所。电脑故障、编程技术、硬件选购这三类问题在协会的咨询群中提问更为快捷，答案也可供后来者查阅。

描述问题的方式直接决定获得答复的速度。电脑故障类的模板为：使用的是什么电脑，何时出现何种问题，是否反复出现，出现问题前做过什么，出现问题时电脑有何反应，并附图展示屏幕内容。选购建议类的模板为：希望购买什么，用途是什么，预算为多少。

**表 14-4　提问的正例与反例**

| | 内容 |
|---|---|
| 反例 | 电脑打不开了怎么办 |
| 正例 | 我的电脑是天选 6 Pro，已有一周未使用，今天开机时无法启动，连接电源后也没有反应，请问应如何处理 |

反例中没有有效信息，他人只能反复追问，往往耗时半小时以上。正例中包含机型、时间、现象以及已排除的可能，了解情况的人可以直接给出判断方向。

**表 14-5　报修时该提供的信息**

| 信息 | 为什么需要 |
|---|---|
| 机型 | 不同机型的问题和拆法不同 |
| 系统版本 | 按 Win+R 输入 winver 查询 |
| 故障开始时间 | 判断是否由近期改动引起 |
| 故障前的操作 | 安装了什么软件、修改了什么设置 |
| 报错截图 | 报错原文是最有价值的线索 |
| 已经试过哪些办法 | 避免他人重复已经做过的排查 |

## 14.5 自学方向

本教程覆盖的是基础操作，继续深入学习可从以下几个方向入手。

**表 14-6　进阶方向与相应资源**

| 方向 | 资源 |
|---|---|
| 系统操作进阶 | 新生电脑讲座的进阶篇，涉及分区调整、文件迁移、系统重装 |
| 编程入门 | 学校的 C 语言课程，协会的 C 语言考前串讲 |
| 硬件知识 | 协会编写的笔记本选购指南、拆机教程 |
| 效率工具 | 微软官方的 PowerToys，可重映射键盘、批量重命名、分屏布局 |
| 计算机基础 | 廖雪峰的官方网站、各高校公开课 |

自学的关键在于遇到问题先自行查阅再请教他人。查阅本身即在积累判断力，而这正是第 12 章所述的、决定能否安全使用 AI 的关键。
