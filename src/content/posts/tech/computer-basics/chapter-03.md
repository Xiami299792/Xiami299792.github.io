**本章要点**

- 掌握功能键 F1 到 F12 的通用含义。
- 能使用编辑键与导航键在文字和页面之间快速定位。
- 理解 Fn 键的作用，掌握功能键默认行为的切换方法。
- 掌握组合键的正确按法。

## 3.1 功能键 F1 到 F12

键盘最上方一排 F1 到 F12 称为功能键，其作用分为两个层面：通用含义来自 Windows 与办公软件的长期约定，具体含义由当前运行的程序决定。

**表 3-1　功能键的通用含义**

| 按键 | 通用含义 | 常见用途 |
|---|---|---|
| F1 | 帮助 | 在几乎所有软件中打开帮助文档 |
| F2 | 重命名 | 在文件管理器中重命名，在 Excel 中编辑单元格 |
| F3 | 搜索 | 在文件管理器中搜索当前目录 |
| F4 | 展开列表 | 在资源管理器中展开地址栏历史 |
| F5 | 刷新 | 刷新浏览器网页，在 PPT 中开始放映 |
| F6 | 切换焦点 | 在浏览器中将光标移至地址栏 |
| F7 | 检查 | 在 Word 中进行拼写与语法检查，在命令提示符中翻查历史命令 |
| F8 | 高级启动 | 开机时按住可进入高级启动选项 |
| F9 | 重新计算 | 在 Excel 中重新计算所有公式 |
| F10 | 菜单栏 | 激活菜单栏 |
| F11 | 全屏 | 浏览器全屏，再按一次退出 |
| F12 | 工具 | 打开浏览器开发者工具，在 Office 中另存为 |

其中以下四个使用频率最高，需要单独掌握。

重命名文件按 F2，这是文件管理器中最快的方式，比通过右键菜单操作少两个步骤。

在浏览器中按 F11 进入全屏，观看视频或演示时可隐藏地址栏与标签页，再按一次退出全屏。

刷新网页按 F5，适用于页面无响应或内容未更新的情况。按住 Ctrl 再按 F5 为强制刷新，将忽略缓存重新下载。

Shift+F10 等同于鼠标右键。鼠标失灵或需要纯键盘操作时，可用它调出右键菜单。

> **注意**　在笔记本上直接按 F 键，执行的通常是调节亮度、音量一类的快捷操作。要执行 F 键本身的功能，需先按住 Fn，详见 3.3 节。

## 3.2 编辑键与导航键

编辑键区与方向键区共同用于在文字和页面之间移动。

**表 3-2　编辑与导航键**

| 按键 | 作用 |
|---|---|
| Home | 跳到当前行的行首 |
| End | 跳到当前行的行尾 |
| Ctrl+Home | 跳到文档或页面的开头 |
| Ctrl+End | 跳到文档或页面的结尾 |
| Page Up | 向上翻一屏 |
| Page Down | 向下翻一屏 |
| Insert | 在插入和改写模式之间切换，现已很少使用 |
| Print Screen | 截取整个屏幕，详见 5.3 节 |
| Num Lock | 切换数字键盘区的功能 |
| Scroll Lock | 早期用于锁定表格滚动，现已基本不用 |
| Pause | 早期用于暂停程序输出，现已基本不用 |

Home 与 End 需要单独说明。在浏览器中按 Home 可直接回到页面顶部，按 End 可直接到达页面底部，效率明显高于滚动滚轮，阅读长文档与长网页时尤为实用。

Page Up 与 Page Down 每次翻动一整屏。空格键同样可以向下翻动一屏，Shift+空格向上翻动一屏，双手无需离开主键盘区。

Insert、Scroll Lock 与 Pause 三个键在当前使用场景中基本不再使用，误按也不会造成异常。

## 3.3 Fn 键与功能键的默认行为

F1 到 F12 兼具两种功能：既可执行厂商定义的快捷操作，也可执行 F 键本身。默认执行哪一种功能，由电脑厂商决定。

多数笔记本的默认设置是执行快捷操作，即调节亮度、音量、静音、开关飞行模式等，对应键帽上方印制的图标。

要执行 F 键本身的功能，例如 F2 重命名、F5 刷新，需按住 Fn 再按。这是从台式机转用笔记本时最常见的困惑：台式机上直接按 F2 即可重命名文件，笔记本上需要额外按住 Fn。

也可以将默认行为反转，使 F 键直接执行 F1 到 F12，按住 Fn 时才执行快捷操作。多数机型通过 Fn+Esc 切换，具体方法因厂商而异，可搜索「你的品牌 解锁 Fn 键」。

> **提示**　切换后屏幕不会有任何提示。判断方法是按一次 F5：页面刷新说明已切换到 F 键模式；若只是屏幕亮度变化，说明未切换成功。

## 3.4 组合键的正确按法

组合键也称快捷键，按法是：依次按下各个键，按后面的键时前面的键不能松开，顺序也不可颠倒。

以 Win+Shift+S 为例，正确操作是：先按住 Win 不放，再按住 Shift，保持两个键均不松开，最后按一次 S。

常见的错误是逐个按下并松开，此时系统接收到的是三个独立按键，而非组合键。

组合键中排在前面的键称为修饰键，包括 Ctrl、Shift、Alt、Win 和 Fn。这五个键单独按下不产生任何字符。

组合键无响应时，首先检查输入法是否占用，Ctrl+Shift、Ctrl+空格、Ctrl+句号常被输入法捕获；其次检查 Fn 是否处于锁定状态，以及其他软件是否注册了相同的全局热键。
