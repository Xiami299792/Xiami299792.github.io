**本章要点**

- 能在开始菜单与搜索框中定位已安装的程序。
- 掌握辨认官方网站的四个要点，避免从第三方下载站获取软件。
- 掌握安装包的三种形式，能在安装界面中取消捆绑软件。
- 掌握正确的软件卸载方法，包括清理残留与识别挽留提示。
- 理解管理员权限的作用，明确授予权限的适用情形。

## 9.1 查找已安装的应用程序

单击屏幕最下方的 Windows 徽标，选择展开菜单中的「所有应用」，即可查看电脑上安装的全部程序。菜单按程序首字母分类，单击任一字母可跳转到对应分类。

也可以在顶部搜索框中按名称直接搜索。搜索框的查找速度高于逐层翻阅列表，在不确定软件名称拼写时尤为方便。

## 9.2 下载：辨认官方网站

下载软件是最容易出问题的环节。渠道选择正确，可以避免后续出现大量弹窗和来源不明的图标。

判断一个网站是否为官方网站，看四个方面。

第一，查看网站标题。官方网站的标题只包含软件名或公司名，不会出现「绿色下载」「软件园」「最新官方正式版」一类字样。标题中含有「下载」二字的网站基本都不是官网。

第二，查看网站网址。官方域名通常是公司名或软件名本身，例如钉钉为 dingtalk.com。potplayercn.com 这类在软件名后强行添加「cn」的域名为盗版站。

第三，查看网站内容。官方网站只包含软件本身的介绍、功能说明与下载入口，不会夹杂无关信息或广告。

第四，国外软件通常不设专门的中文官网，标注「某某中文网」「某某中文版」的基本是第三方重新打包的版本。

> **提示**　GitHub 与 SourceForge 上的项目页面通常即为官方网站，许多开源软件只在这两处发布。

## 9.3 版本与安装包形式

同一软件通常提供多个版本，选错会导致无法安装或无法运行。

**表 9-1　常见版本标识的含义**

| 标识 | 含义 |
|---|---|
| 64-bit、x64、amd64 | 64 位版本，当前绝大多数电脑使用该版本 |
| 32-bit、x86 | 32 位版本，仅在较旧的电脑上需要 |
| ARM64 | 用于骁龙等 ARM 架构处理器，少数轻薄本 |
| Setup、Installer | 安装版，下载后双击安装 |
| Portable、绿色版 | 免安装版，解压后即可使用，但不受官方支持 |

如不确定所用电脑属于哪一种，可按 Win+R 输入 winver 查看系统版本，或在任务管理器的「性能」中查看 CPU 型号。

安装包可能有三种形式：exe 或 msi 可直接双击安装；zip 压缩包需要先解压，再从中找到 exe；iso 光盘镜像双击挂载为虚拟光驱，进入后找到安装程序。

无论下载到哪种形式，最终都需要找到其中的 exe 文件并双击运行。

## 9.4 安装流程与避坑

双击安装程序后，按界面提示操作。多数正规软件的流程较为简单：同意用户协议，确认安装位置，选择下一步，等待进度条完成。

安装位置默认为 C 盘。如 7.2 节所述，推荐将软件安装在 C 盘，不建议为节省空间而装到 D 盘。仅在 C 盘空间不足时才需要修改，方法是单击旁边的「浏览」按钮，选择一个 D 盘上的文件夹。

许多国产软件的安装程序不采用上述流程，而是先弹出信息繁杂的界面，将捆绑软件混杂其中。捆绑软件指在安装过程中被附带安装的其他程序——它们并非用户所需，却会出现在电脑上并带来广告与病毒。

**表 9-2　安装界面上必须检查的四处**

| 位置 | 检查内容 |
|---|---|
| 安装路径 | 默认位于 C 盘，确认剩余空间充足 |
| 用户协议中的附加条款 | 常包含「同意安装某某浏览器」「同意将某某设为首页」等条款 |
| 自定义安装与快速安装 | 默认选中快速安装，会一并安装捆绑软件 |
| 安装完成页 | 「立即体验」一类按钮可能同样是安装按钮 |

若安装界面只有两个按钮，一个是较大的「一键安装」，另一个是较小的「自定义安装」，应选择后者。

## 9.5 卸载应用程序

最常见的错误做法是删除桌面图标。桌面上的软件图标带有小箭头，属于快捷方式，仅起指向作用。删除它并不会卸载软件，程序本体仍在硬盘上，仅是无法再从桌面启动。

正确做法是在设置中卸载：按徽标键，进入「设置」→「应用」→「已安装的应用」（Windows 10 中为「应用和功能」），找到目标软件，单击右侧的三个点，再选择卸载。也可以从控制面板进入「卸载程序」，两个入口效果相同。

卸载过程中有三个细节。

若卸载界面询问是否「删除个人数据」或「删除用户配置」，应勾选，以避免残留。

若卸载完成后弹出「修复软件」「尝试最新版」「我要重装」「再想想」一类选项，应一律拒绝，否则软件会被重新安装。

部分软件会将「确认卸载」按钮设置得较小且颜色很淡，同时在旁边放置一个较大的「我再想想」。操作时应放缓速度，确认后再单击。

> **注意**　少数专业软件无法通过设置完全卸载，例如 SolidWorks，这类软件需按官方提供的卸载教程操作。

## 9.6 管理员权限与高风险软件

C 盘中包含大量重要的系统文件与文件夹，不当操作可能导致系统损坏，因此系统默认不允许普通操作修改这些位置。但安装与卸载软件时必须向 C 盘添加或删除文件，此时系统会弹出窗口询问是否允许，该机制称为用户账户控制。

应当选择「是」的情形是：正在主动安装或卸载自己了解来源的软件，且该弹窗刚刚出现。

应当选择「否」的情形是：未进行任何操作而弹窗自行出现。此类弹窗有时会伪装成系统更新或杀毒提示，应一律选择「否」，随后回想近期安装过哪些软件。

右键菜单中还有「以管理员权限运行」一项。除教程明确要求外，平时不应使用。

**表 9-3　三类软件的安装风险**

| 软件类型 | 风险 | 建议 |
|---|---|---|
| 普通常用软件 | 低，主要是捆绑软件 | 按 9.4 节的做法取消勾选 |
| 大型专业软件 | 中，依赖组件多，安装错误需要清理 | 严格按可靠的教程操作，不要跳过步骤 |
| 涉及系统底层的工具 | 高，可能影响系统启动 | 没有把握时联系电脑诊所 |

许多国外专业软件，例如 SolidWorks、Inventor、MATLAB，正版获取渠道有限，安装与卸载流程复杂，中途出错严重时可能需要重装系统。安装前应确认系统版本、硬盘空间是否满足要求，以及是否存在必须先安装的运行库。安装过程中不要中途关闭，也不要同时安装其他软件。
