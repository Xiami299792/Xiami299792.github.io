表 A-1 全局常用快捷键

| 快捷键 | 作用 |
|---|---|
| Win | 打开或关闭开始菜单 |
| Win+E | 打开文件资源管理器 |
| Win+D | 显示桌面，再按恢复 |
| Win+L | 锁屏 |
| Win+I | 打开设置 |
| Win+S | 搜索文件和程序 |
| Win+R | 打开运行框 |
| Win+V | 剪贴板历史 |
| Win+X | 打开开始按钮的右键菜单 |
| Win+Shift+S | 区域截图 |
| Win+Shift+R | 区域录屏 |
| Win+Print Screen | 全屏截图并存成文件 |
| Win+Tab | 任务视图 |
| Win+Ctrl+D | 新建虚拟桌面 |
| Win+Ctrl+左右方向键 | 切换虚拟桌面 |
| Win+方向键 | 窗口贴边、最大化、最小化 |
| Win+Z | 贴靠布局 |
| Win+数字 1 到 9 | 打开任务栏上第 n 个程序 |
| Win+空格 | 切换输入法 |
| Win+句号 | 表情和符号面板 |
| Win+Ctrl+O | 屏幕键盘 |
| Alt+Tab | 切换窗口 |
| Alt+F4 | 关闭当前窗口 |
| Alt+空格 | 窗口控制菜单 |
| Ctrl+Shift+Esc | 任务管理器 |
| Ctrl+Shift+N | 新建文件夹 |
| Delete | 删除到回收站 |
| Shift+Delete | 永久删除 |
| F2 | 重命名 |
| F5 | 刷新 |

表 A-2 编辑与浏览器快捷键

| 快捷键 | 作用 |
|---|---|
| Ctrl+C / Ctrl+V | 复制，粘贴 |
| Ctrl+X | 剪切 |
| Ctrl+Z / Ctrl+Y | 撤销，重做 |
| Ctrl+A | 全选 |
| Ctrl+S | 保存 |
| Ctrl+F | 查找 |
| Ctrl+P | 打印 |
| Ctrl+T / Ctrl+W | 新建标签页，关闭标签页 |
| Ctrl+Shift+T | 恢复刚关闭的标签页 |
| Ctrl+Tab | 下一个标签页 |
| Ctrl+数字 1 到 8 | 跳到第几个标签页 |
| Ctrl+D | 收藏当前页 |
| Ctrl+H | 历史记录 |
| Ctrl+J | 下载内容 |
| Ctrl+加号或减号 | 放大缩小页面 |
| Ctrl+滚轮 | 缩放 |
| Ctrl+Shift+N | 无痕窗口 |
| Home / End | 跳到行首，行尾 |
| Ctrl+Home / Ctrl+End | 跳到文档开头，结尾 |
| Page Up / Page Down | 向上，向下翻一屏 |
