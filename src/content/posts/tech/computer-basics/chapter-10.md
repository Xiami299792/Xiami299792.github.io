**本章要点**

- 掌握有线与无线网络的连接方法，理解光猫与路由器的区别。
- 会用浏览器的标签页、收藏夹和下载管理。
- 掌握以关键词而非整句搜索的方法，了解可提高检索精度的符号。
- 了解常用网站的类别与推荐站点。

## 10.1 连接网络

与手机不同，浏览器几乎是电脑上访问互联网的唯一工具。查阅资料、下载软件、观看视频均通过浏览器完成。

从墙上的网口到电脑之间存在一条链路：宽带进户接光猫，光猫接路由器，路由器通过网线或 Wi-Fi 连接电脑。

光猫与路由器通常是两个外形相近的盒子叠放在一起，也可能被运营商集成为一个设备。分辨方法是查看背面标签：标注「光猫」「ONU」「光调制解调器」并接有细光纤线的为光猫；标注「路由器」「无线路由器」并带多根天线的为路由器。若家中只有一个盒子，则两种功能由同一设备承担。

电脑联网有两种方式。

有线：使用一根网线，一端连接路由器，另一端连接电脑网口。有线连接速度更稳定、延迟更低，台式机建议采用有线方式。

无线：单击任务栏右下角的网络图标，在列表中找到目标 Wi-Fi 名称，选择连接并输入密码。

并非所有电脑都能连接 Wi-Fi。笔记本均具备该功能；部分台式机没有内置无线网卡，需要另配 USB 无线网卡并插入机箱的 USB 接口。也可以用数据线或手机热点共享网络，足以应对临时需求。

Wi-Fi 名称后有时会标注 2.4G 或 5G。此处的 5G 指频段，与手机通信中的 5G 无关。

**表 10-1　两个 Wi-Fi 频段的取舍**

| 频段 | 优点 | 缺点 | 适用场景 |
|---|---|---|---|
| 2.4G | 穿墙能力强，覆盖范围广 | 速度较慢，干扰较多 | 需要穿过多道墙体时 |
| 5G | 速度快，延迟低 | 穿墙能力弱 | 在同一房间内使用 |

两个频段由同一台路由器发出，密码通常相同。

## 10.2 浏览器

Windows 上主流的浏览器内核只有两个：Chromium 与 Gecko。Chrome、Edge 以及 360、QQ、搜狗等国产浏览器都基于 Chromium，Firefox 用 Gecko。内核相同不代表体验相同，但渲染网页的能力基本一致。Windows 电脑已预装 Edge，可直接使用。

浏览器界面自上而下分为几个区域。地址栏位于最上方，既可输入网址也可输入搜索词；地址栏左侧是后退、前进、刷新按钮，右端是收藏、扩展与账户图标；其上为标签页栏，每个标签页对应一个网页；右上角三个点为菜单，历史记录、收藏夹、下载内容与无痕窗口均在其中。

收藏网页可单击地址栏右侧的五角星图标，或按 Ctrl+D。将常用网站加以收藏，比每次搜索更快捷。收藏较多后，按 Ctrl+Shift+O 可打开收藏夹管理，删除不再需要的内容。

按 Ctrl+J 可查看下载列表。浏览器下载的文件默认保存到「下载」文件夹，该文件夹位于 C 盘，下载大文件后应及时转移，详见 13.2 节。

**表 10-2　浏览器常用快捷键**

| 快捷键 | 作用 |
|---|---|
| Ctrl+T | 新建标签页 |
| Ctrl+W | 关闭当前标签页 |
| Ctrl+Shift+T | 恢复刚关闭的标签页 |
| Ctrl+Tab | 切到下一个标签页 |
| Ctrl+数字 1 到 8 | 跳到第几个标签页 |
| Ctrl+9 | 跳到最后一个标签页 |
| Ctrl+L | 光标跳到地址栏 |
| Ctrl+D | 收藏当前页 |
| Ctrl+F | 在当前页面里查找文字 |
| Ctrl+H | 打开历史记录 |
| Ctrl+J | 打开下载内容 |
| Ctrl+加号或减号 | 放大缩小页面 |

无痕模式的快捷键是 Ctrl+Shift+N。该模式不留下浏览历史、Cookie 和表单记录，关闭窗口即清除。无痕模式并不等于隐身，网络运营商与学校网络管理员仍可看到访问了哪些网站，它防范的是同一台电脑上的其他使用者。

## 10.3 搜索引擎

搜索服务由搜索引擎提供。常见的有百度和必应，推荐使用必应，它也是 Edge 浏览器的默认搜索引擎。

搜索的第一条原则是：不要输入完整句子，而应使用概括性的关键词。搜索引擎按词匹配，句子中的「请问」「帮我」「怎么办」都属于无效成分。

第二条原则：多个关键词之间用空格分隔。

**表 10-3　搜索关键词的写法**

| 检索目的 | 检索词 |
|---|---|
| 学校官网 | 北理工 官网 |
| 教务部 | 北理工 教务部 |
| 下载 QQ | QQ 下载 |
| 某个报错的解决办法 | 报错原文加英文双引号 |

为关键词添加英文双引号后，搜索将按整句匹配，不再拆分词语，这是查询报错信息最有效的方法。双引号的输入方法：确认输入法处于英文状态，按住 Shift 再按回车键左侧的引号键。

还有两个符号需要了解。在词后加 site: 与域名，例如「考研 site:edu.cn」，可限定在该域名下搜索。在词前加减号，例如「苹果 -手机」，可排除包含「手机」的结果。

## 10.4 常用网站

**表 10-4　常用网站推荐**

| 类别 | 网站 |
|---|---|
| 网课与学科知识 | 哔哩哔哩（bilibili.com）、知乎（zhihu.com） |
| 计算机知识 | 廖雪峰的官方网站（liaoxuefeng.com）、掘金（juejin.cn）、博客园（cnblogs.com） |
| 开源项目 | GitHub（github.com）、GitLab（gitlab.com）、SourceForge（sourceforge.net）、Gitee（gitee.com） |
| 校内 | i 北理、教务部网站、图书馆网站 |

查阅技术内容时，社区与官方文档的质量通常高于聚合类博客站。遇到问题应先查官方文档，再参考社区讨论。
