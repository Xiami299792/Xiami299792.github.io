表 C-1 术语对照

| 名词 | 一句话解释 |
|---|---|
| 操作系统 | 管理硬件与系统资源、提供桌面环境和文件系统的软件 |
| 驱动 | 操作系统与硬件之间的接口，硬件异常时优先检查 |
| A 面 / B 面 / C 面 / D 面 | 笔记本的顶盖、屏幕边框、键盘面、底部 |
| 内存 | 软件运行时存放临时数据的空间，关机后清空 |
| 储存 | 长期存放文件的空间，由硬盘承担 |
| 固态硬盘 | 以闪存芯片作为存储介质的硬盘，速度快 |
| 机械硬盘 | 以磁盘盘片作为存储介质的硬盘，速度较慢但成本低 |
| 核显 | CPU 集成的显卡，可满足办公与影音需求 |
| 独立显卡 | 独立安装的显卡，仅在游戏或视频剪辑时需要 |
| 分区 | 将一块硬盘划分为多个盘符，C 盘、D 盘即为分区 |
| 卷标 | 分区的名称，可以任意修改 |
| 盘符 | 分区的字母，不建议修改 |
| 路径 | 文件的完整地址，由分区逐层限定 |
| 主名 | 文件名的名称部分 |
| 扩展名 | 文件名末尾的字母，决定用何种程序打开 |
| 资源管理器 | 也称文件资源管理器，用于查看和管理文件的窗口，Win+E 打开 |
| 快捷方式 | 指向目标文件的链接，删除后不影响原文件 |
| 回收站 | 已删除文件的暂存区域，可以还原 |
| 进程 | 正在运行的程序实例，一个软件可能同时存在多个 |
| 服务 | 系统中常驻的一批后台程序 |
| 后台 | 程序窗口已关闭但仍在运行的状态 |
| 启动项 | 开机时自动运行的程序，数量过多会延长开机时间 |
| 缓存 | 程序为加速运行而保留的临时数据，可以清理 |
| 剪贴板 | 复制的内容暂存于此，由 Ctrl+V 取出 |
| 捆绑软件 | 安装过程中被附带安装的其他程序，通常带来广告 |
| 官网 | 由软件开发者或公司自行运营的网站，判断方法见 9.2 节 |
| 管理员权限 | 修改系统文件所需的更高权限 |
| 用户账户控制 | 系统在需要管理员权限时弹出的确认窗口 |
| 光猫 | 将光纤信号转换为网络信号的设备 |
| 路由器 | 将网络分配给各终端设备的设备，Wi-Fi 由其发出 |
| 无线网卡 | 使电脑能够连接 Wi-Fi 的硬件 |
| IP 地址 | 设备在网络中的地址标识 |
| 域名 | 网址中的名称部分，例如 www.baidu.com |
| DNS | 将域名解析为 IP 地址的服务 |
| 网关 | 网络的出口设备，通常为路由器 |
| 带宽 | 网络每秒可传输的数据量，单位为 Mbps |
| 搜索引擎 | 提供网页搜索服务的网站，如必应、百度 |
| 无痕模式 | 不留下本地浏览历史的浏览器模式 |
| 钓鱼 | 假冒正规机构骗取账号密码的手段 |
| 两步验证 | 登录时除密码外还需第二个凭证 |
| 备份 | 将数据另存一份 |
| 3-2-1 备份 | 三份数据、两种存储介质、一份存放于其他位置 |
| 还原点 | 系统设置与驱动的快照，出现问题时可以回退 |
| 硅脂 | 填充在热源和散热模组之间的导热材料 |
| 液金 | 导热性能更好的液态金属，使用后有保持水平的要求 |
| 电池养护模式 | 将充电上限限制在 80% 左右以延长电池寿命的功能 |
| AI 幻觉 | AI 生成看似合理、实际不存在或错误的内容 |
| 电脑诊所 | 网络开拓者协会提供的校内电脑维修服务 |
