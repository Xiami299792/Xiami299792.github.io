**本章要点**

- 掌握键盘五个分区的划分及各按键的作用。
- 掌握中文输入法的选字、翻页与整句输入。
- 理解中英文符号的区别，避免密码与网址输入错误。
- 养成正确的打字指法。

## 2.1 键盘的布局

键盘可划分为五个区域。

主键盘区位于最左侧，包含字母、数字和符号，是输入的主要区域。

功能键区是顶部的 F1 到 F12，见 3.1 节。

编辑键区位于主键盘区与数字键盘区之间，包含 Insert、Home、End、Page Up、Page Down，见 3.2 节。

方向键区由四个箭头键组成，用于移动光标或在表格中定位。

数字键盘区位于最右侧，用于快速输入数字。该区上方有 Num Lock 键，指示灯熄灭时该区转为方向键功能，无法输入数字。

键盘输入时，文字出现在光标所在位置。找不到光标时，先单击准备输入的位置。

## 2.2 常用按键的功能

**表 2-1　主键盘区常用按键**

| 按键 | 英文 | 作用 |
|---|---|---|
| 回车键 | Enter | 确认输入、另起一行、打开选中的项目 |
| 退格键 | Backspace | 删除光标前一个字符 |
| 删除键 | Delete | 删除光标后一个字符 |
| 换档键 | Shift | 按一次切换中英文，按住时输入大写 |
| 大写锁定键 | Caps Lock | 按下后切换大小写，灯亮为大写 |
| 空格键 | Space | 输入一个空格 |
| 制表键 | Tab | 在输入框之间跳转，文档中用于缩进 |
| 退出键 | Escape | 取消当前操作，关闭弹窗 |
| 控制键 | Control | 组合键用，单独按无作用 |
| 徽标键 | Windows | 组合键用，打开开始菜单 |

退格键与删除键的区别需要单独注意：退格键删除光标之前的字符，删除键删除光标之后的字符。

Tab 键还有一项用途：在网页表单中按该键可在各个输入框之间依次跳转，无需使用鼠标。

## 2.3 中文输入法

中文输入的基本原理是：用键盘上的英文字母输入拼音，再从系统给出的候选词中选择汉字。例如输入「张」，依次按 z、h、a、n、g，输入框下方即列出候选字。

选字有三种方式。按空格键选取第一个候选字，多数情况下第一个即所需字符。按数字键选取对应编号的候选字。所需字符不在当前页时，按加号或减号翻页，部分输入法使用 Page Up 与 Page Down，取决于所安装的输入法。

初学者最常见的做法是逐字输入。可改用整句输入：将「今天下午三点开会」的拼音一次输入完毕再选词，输入法会结合上下文推断，准确率明显高于逐字选取。

**表 2-2　输入法常用快捷键**

| 快捷键 | 作用 |
|---|---|
| Shift | 中英文切换，输入时使用频率最高 |
| Ctrl+空格 | 中英文切换，旧有习惯 |
| Win+空格 | 在已安装的多个输入法之间切换 |
| Ctrl+Shift | 在多个输入法之间轮换 |
| Shift+空格 | 全角半角切换 |
| Ctrl+句号 | 中文标点和英文标点切换 |
| Caps Lock | 英文大小写锁定 |

生僻字可以采用拆字输入：先输入字母 u，再将字拆开输入。例如输入「犇」，先输 u 再输三个「牛」的拼音即可找到。

输入法会记录常用词。某个专业名词首次输入时可能需要逐字选取，数次之后即会排到候选前列。也可以添加自定义短语，将学号、邮箱一类高频长串设置为数个字母的缩写。

## 2.4 中文符号与英文符号

键盘上的符号键有中英文两套。除了字形不同，中文符号通常比英文符号更宽，因为中文符号占两个字符的位置。

**表 2-3　常见符号的中英文对照**

| 按键 | 英文符号 | 中文符号 |
|---|---|---|
| 逗号 | 「,」 | 「，」 |
| 句号 | 「.」 | 「。」 |
| 分号 | 「;」 | 「；」 |
| 问号 | 「?」 | 「？」 |
| 单引号 | 直引号 | 成对的弯引号 |
| 尖括号 | 「<」 | 「《」 |
| 数字 6 加 Shift | 「^」 | 「……」 |
| 数字 4 加 Shift | 「$」 | 「￥」 |

切换方式是按 Ctrl 加句号。输入法状态栏上会显示当前是中文标点还是英文标点。

> **注意**　密码、网址、电子邮箱地址必须在英文符号状态下输入。中文逗号与英文逗号外观差别很小，但系统可以识别，密码框会持续提示错误而原因难以察觉。同理，网址中的英文句点与中文句号混用会导致网页无法打开。

## 2.5 打字指法

指法应在开始使用时即练成正确姿势，事后纠正比初次学习更为困难。

键盘上的 F 和 J 两个键各有一个凸点，作为定位点，无需目视即可触摸到。左手食指置于 F，右手食指置于 J，其余手指依次落在相邻键上，两个拇指负责空格键。这就是基准姿势。

每输入完一段文字，手指应回到基准位置。养成这一习惯才能实现盲打。

练习盲打时，可以用布遮盖手部与键盘，依靠凸点定位。初期会感到不适。如难以适应也不必勉强，先保证手指放在正确位置，打字时不看键盘，速度会逐步提高。
