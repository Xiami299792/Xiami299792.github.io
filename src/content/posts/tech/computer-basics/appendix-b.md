Win+R 打开运行框，输入以下命令并回车，可直接打开对应系统工具。名称中带 .msc 的，需连同这四个字母一并输入。

表 B-1 Win+R 常用命令

| 命令 | 打开 |
|---|---|
| control | 控制面板 |
| taskmgr | 任务管理器 |
| devmgmt.msc | 设备管理器，用于检查驱动 |
| diskmgmt.msc | 磁盘管理，用于查看分区和盘符 |
| cleanmgr | 磁盘清理（微软已逐步转向「设置」→「系统」→「存储」） |
| appwiz.cpl | 程序和功能，用于卸载软件 |
| ncpa.cpl | 网络连接，用于设置网卡 |
| services.msc | 服务 |
| eventvwr.msc | 事件查看器，用于排查崩溃原因 |
| dxdiag | 查看硬件信息 |
| winver | 查看 Windows 版本 |
| ms-settings: | 打开设置 |
| osk | 屏幕键盘 |
| notepad | 记事本 |
| calc | 计算器 |
| mspaint | 画图 |
| shell:startup | 开机自启文件夹 |
| %temp% | 当前用户的临时文件夹 |
