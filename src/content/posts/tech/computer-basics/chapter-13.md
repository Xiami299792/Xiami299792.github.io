**本章要点**

- 能判断 C 盘空间是否紧张，并使用系统自带功能清理冗余文件。
- 明确哪些个人文件夹默认位于 C 盘及其处理办法。
- 会用电池养护模式延长电池寿命。
- 理解笔记本的散热原理，明确发热严重时的处理措施。

## 13.1 磁盘空间与垃圾清理

随着使用时间增加，C 盘中的冗余文件不断累积，可用空间逐渐减少。一个经验阈值是：C 盘剩余空间小于 30 GB 时可能引起系统响应迟缓，需要清理。

日常最简便的做法是定期清理常用软件的缓存，包括 QQ、微信、钉钉、剪映等。这些软件会将聊天记录中的图片、视频和文件默认保存在 C 盘，长期使用后单个软件可占用数十 GB。清理入口通常在软件的「设置」→「存储」中。

系统自带两个清理工具，其清理效果比手动逐层查找目录更为彻底。

**表 13-1　两个系统清理工具**

| 工具 | 使用方法 | 清理内容 |
|---|---|---|
| 磁盘清理 | 在开始菜单中搜索「磁盘清理」，选择 C 盘扫描，先单击「清理系统文件」再勾选 | 系统临时文件、Windows 更新残留、缩略图缓存 |
| 存储感知 | 设置 → 系统 → 存储，打开开关并配置 | 按设定频率自动清理临时文件与回收站 |

磁盘清理的勾选列表里有三项不可逆，勾之前想清楚：「以前的 Windows 安装」（清理后无法退回上一个系统版本）、「Windows 更新清理」（清理后已安装的补丁无法卸载）、「系统错误内存转储文件」（蓝屏现场，蓝屏原因还没查清时不要勾）。其余各项系统都会自动重建。

还有几个确定安全的临时目录可以手动清理。

**表 13-2　可以安全清理的临时目录**

| 目录 | 里面是什么 |
|---|---|
| C:\Windows\Temp | 系统临时文件 |
| C:\Windows\SoftwareDistribution\Download | Windows 更新的下载缓存 |
| %temp% | 当前用户的临时文件，等同于 C:\Users\你的用户名\AppData\Local\Temp |

第一行的 C:\Windows\Temp 与第三行的 %temp% 可以直接全选删除，系统需要时会自动重建。第二行的 SoftwareDistribution\Download 要绕一步：它是 Windows 更新服务的工作区，服务运行时对它有占用，直接删会删不干净，还可能让更新组件误以为补丁已经下载，从此卡住不再安装。正确做法是先用管理员身份打开命令提示符，依次执行 net stop wuauserv 与 net stop bits 停掉服务，再删除该目录里面的内容（Download 这一层文件夹保留），最后执行 net start wuauserv 与 net start bits 恢复。嫌麻烦也可以不动它，交给表 13-1 的磁盘清理。除此之外，C:\Windows 下的其他内容仍不可改动。

第三行的 %temp% 是一种简写形式，在地址栏或 Win+R 中输入 %temp% 后回车，将自动跳转到对应的真实路径。

进入这些目录后按 Ctrl+A 全选，再按 Delete 删除。此处不使用 Shift+Delete，因为临时文件中可能混有仍需保留的内容，删除后进入回收站尚可恢复。删除时会有部分文件提示「正在使用」，跳过即可。

> **警告**　网络上流传的「一键清理」批处理脚本，来源不明的一律不得运行。清理类脚本的功能即为删除文件，路径书写错误会造成严重后果。清理 C 盘、调整分区、克隆数据都属于有风险的操作，没有把握时应预约电脑诊所。

## 13.2 个人文件夹的存放位置

电脑上有几个文件夹的默认存放路径位于 C 盘，将个人文件长期存放其中并不合适。

**表 13-3　默认在 C 盘的个人文件夹**

| 文件夹 | 默认路径 | 建议 |
|---|---|---|
| 桌面 | C:\Users\你的用户名\Desktop | 仅存放临时文件，大文件及时转移 |
| 文档 | C:\Users\你的用户名\Documents | 重要资料转移至数据盘 |
| 下载 | C:\Users\你的用户名\Downloads | 定期清空，不作为长期存放位置 |
| 图片 | C:\Users\你的用户名\Pictures | 照片与素材转移至数据盘 |
| 视频 | C:\Users\你的用户名\Videos | 视频体积大，优先转移 |

有两种处理办法。一种是修改路径：右键单击该文件夹，选择「属性」，切换到「位置」选项卡，单击「移动」，选择数据盘上已建立的目标文件夹并确认。系统会询问是否一并移动现有文件，选择是。另一种更为简便：不使用这些文件夹，改在数据盘上自行建立目录。

> **注意**　安装系统时若选择用 OneDrive 备份桌面和文档，这两个文件夹的位置会被改到 OneDrive 之下，路径显著变长。文件仍然存在，只是位置发生了变化。

## 13.3 电池养护

笔记本电池的损耗主要来自两个方面：放电循环次数，以及长期处于高电量状态。

连接充电器且电量充满后，电脑由电源适配器直接供电，电池基本不再放电，循环次数因此减少；但电池长期停留在 100%，高电压又会加快老化。综合两方面，结论是尽可能插电使用，同时将电量上限控制在 80% 左右。多数品牌提供了该功能，称为电池养护模式或充电阈值。

**表 13-4　开启电池养护的方法**

| 步骤 | 操作 |
|---|---|
| 1 | 搜索「你的品牌名 电池养护模式」，例如「联想 电池养护模式」 |
| 2 | 按搜索结果进入厂商自带的电源管理软件 |
| 3 | 将充电上限设置为 80% |
| 4 | 此后连接电源使用时，电量停留在 80% 不再上升 |

> **提示**　携带电脑外出前，应临时将上限调整为 100%，否则断开电源后仅有约 80% 的电量可用。

另外，电池图标上有时会出现「智能充电」，系统自行把电量临时压在 80% 左右。这是系统在保护电池，不是故障，用一段时间后会自行恢复充满。

## 13.4 散热原理与优化

笔记本发热属于正常现象，但散热不良会导致降速、黑屏甚至死机。

CPU、显卡等部件是热源，热量通过散热模组向两侧传导，风扇产生空气流动，将热量随空气带出机身。热源与散热模组之间需要填充导热材料，因为空气的导热性能很差。通常使用硅脂，部分高性能机型使用液金，即镓、铟、钠一类合金。

判断散热是否不足，可观察三个迹象：机身表面明显发热、风扇长时间高速运转、间歇性突然黑屏或死机。

**表 13-5　改善散热的四种做法**

| 做法 | 作用 |
|---|---|
| 清灰、更换硅脂 | 提升机身导出热量的能力 |
| 使用电脑支架 | 抬高机身，加大底部进风量 |
| 移除电脑旁的杂物 | 保证出风口不被遮挡 |
| 摘除键盘膜、贴纸、保护壳 | 加强机身表面的热量释放 |

在保养周期上，轻薄本一般一年半到两年清灰换一次硅脂，游戏本等高负载机型一年一次，环境灰尘多或养宠物则缩到半年到一年。比日历更可靠的是症状：风扇长时间高速运转、键盘与出风口明显烫手、无故降频或死机，出现两条就该安排清灰换硅脂。

> **警告**　使用液金的电脑在冷却前必须保持水平，防止液金偏移。液金一旦流到主板上会造成短路，后果严重。此类机器的清灰与换硅脂不建议自行操作。
