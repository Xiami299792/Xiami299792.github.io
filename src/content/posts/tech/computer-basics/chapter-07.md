**本章要点**

- 理解分区、卷标与盘符，掌握分区的规划原则。
- 能根据扩展名判断文件类型，理解显示扩展名可以防范病毒的原因。
- 能读懂文件路径并用其准确定位文件。
- 明确哪些系统目录不可修改。

## 7.1 硬盘分区

一块硬盘可以划分为若干个分区，即「此电脑」中显示的 C 盘、D 盘。

每个分区有两个属性。卷标是分区的名称，例如可将 D 盘命名为「Document」，卷标可以任意修改；盘符是分区的字母，如 C、D、E，盘符不可随意更改。

**表 7-1　卷标与盘符的区别**

| 属性 | 是什么 | 能否修改 |
|---|---|---|
| 卷标 | 分区的名称，如「Document」 | 可以任意修改 |
| 盘符 | 分区的字母，如 C、D、E | 不建议修改 |

C 盘有特殊地位：它是 Windows 系统本身存放的位置，系统文件、驱动和默认安装的软件都在这里。

## 7.2 分区的原则

分区一经确定便不易修改，一开始就应估好大小。三条原则如下。

第一条，系统盘容量要充足。建议为 C 盘分配 300 GB 以上，512 GB 更为从容。低于该数值，安装若干专业软件后空间即会紧张。

第二条，不需要单独划分一个分区用于安装软件。软件安装在容量足够的 C 盘中即可。

第三条，除系统盘之外，剩下的空间全部给一个数据盘。不要按内容划分为「文档」「音乐」「游戏」「杂项」等多个分区。

分设多个分区会带来明显问题，下面是一个常见的反例。

**表 7-2　两种分区方案的对比**

| 方案 | 分区方式 | 问题 |
|---|---|---|
| 不推荐 | OS(C:)、文档(D:)、音乐(M:)、游戏(G:)、杂项(O:) | 各分区均有剩余但均不敷使用，新游戏无处存放 |
| 推荐 | OS(C:)、包罗万象(D:) | 以文件夹分类，灵活，可随时新建与调整 |

多分区的根本问题在于容量被固定分配——若给游戏分配 200 GB，装入三个大型游戏后即告用尽，而音乐分区空余 150 GB 也无法调用。以文件夹分类则不存在这一问题：空间为各文件夹共享。

只保留一个 C 盘、将个人文件全部存放其中的做法，会在重装系统时带来问题，因为重装需要清空原有系统分区。

**表 7-3　保留数据盘的意义**

| 场景 | 只有 C 盘 | 有 C 盘和 D 盘 |
|---|---|---|
| 重装系统 | 个人文件必须提前转移，否则全部丢失 | C 盘完全改变，D 盘数据完全保留 |

## 7.3 文件与文件夹

文件是电脑中存储数据的最小单位，一张照片是一个文件，一份论文也是一个文件。文件夹是用于分类存放文件的容器。

同一个文件夹下不能存在两个同名文件，如需保存两份「报告」，必须重命名或放入不同的文件夹。

分区下可以存放若干文件与文件夹，每个文件夹内又可存放若干文件与文件夹，逐层嵌套，这一结构决定了文件路径的写法。

严格来说，「桌面」并非独立位置，它是 C:\Users\你的用户名\Desktop 文件夹在屏幕上的呈现。将文件拖到桌面，文件实际存放在该文件夹中并占用 C 盘空间。

## 7.4 文件名与扩展名

一个文件名由主名和扩展名组成，中间用一个英文句点分隔。

以「校园风景.png」为例，前面是主名，即文件名；「png」是扩展名，表示文件类型。扩展名的作用是告知系统应使用何种软件打开该文件。

**表 7-4　常见扩展名分类**

| 类型 | 常见扩展名 |
|---|---|
| 电子书 | pdf、epub、mobi |
| 图片、视频、音频 | png、jpg、gif、mp4、flv、mp3、flac |
| 应用程序 | exe、msi |
| 压缩文件 | zip、7z、rar |
| 文档与表格 | docx、pptx、xlsx、txt |

同一类型可能对应多种格式，区别在于用途。jpg 体积较小，适合照片；png 支持透明背景，适合截图。

还有几个扩展名需要单独认识。

**表 7-5　其他常见扩展名**

| 扩展名 | 是什么 | 注意事项 |
|---|---|---|
| dll | 程序的依赖库 | 不要改动，删除后软件会报错 |
| iso | 光盘镜像 | 双击可挂载，也可写入 U 盘制作启动盘 |
| bat | 批处理脚本，一段可自动执行的命令 | 来源不明时不要双击 |
| reg | 注册表文件，用于修改系统核心设置 | 导入错误可能导致系统异常 |
| lnk | 快捷方式 | 双击跳转到目标文件 |

Windows 默认隐藏扩展名，这是许多问题的来源。打开任意文件夹窗口，在顶部菜单栏中选择「查看」，其中有一排带图标的功能项，找到「文件扩展名」并单击，使其前方出现勾选标记。Windows 10 的路径不同，直接在「查看」选项卡中勾选「文件扩展名」复选框。

开启扩展名显示最主要的作用是防范病毒。名为「假期照片.jpg」的是图片，名为「假期照片.jpg.exe」的是程序，扩展名隐藏时两者几乎没有差别。文件名中包含两个句点的文件不应双击。

压缩包按格式分为三种：zip 系统始终可以直接打开；rar 和 7z 自 Windows 11 的 23H2 版本起也可以直接打开；更早的系统需要安装 7-Zip 或 WinRAR。

## 7.5 文件路径

从分区开始逐层向下，每个文件都有对应的地址，称为文件的路径。

**表 7-6　文件路径的读法**

| 层次 | 对应内容 |
|---|---|
| 分区 | D 盘 |
| 第一层文件夹 | 杂物 |
| 第二层文件夹 | 证件照 |
| 文件 | 红底.jpg |
| 完整路径 | D:\杂物\证件照\红底.jpg |

读法为从右向左：名为红底的图片位于「证件照」文件夹中，「证件照」位于「杂物」文件夹中，「杂物」位于 D 盘上。反斜杠是分层的分隔符，每一层都缩小一次范围。

这与邮寄地址的原理相同。地址写成「北京市 房山区 良乡东路 9 号」，逐层缩小范围，最终定位到具体地点。文件路径即以文件夹与文件名替代地址的各个层级。

在文件管理器的地址栏中单击空白处，路径即成为可复制的文本。如需日后快速定位，可按 Win+R 调出左下角的「运行」对话框，粘贴路径后按回车即可直达。

C 盘中有三类目录名称需要识别，但均不需要进入操作。

**表 7-7　C 盘的主要目录**

| 目录 | 说明 | 是否可修改 |
|---|---|---|
| C:\Windows | 系统本体 | 不可修改，其中的文件一个都不能删 |
| C:\Program Files | 软件安装位置 | 不要手动删除，卸载软件应通过正常流程 |
| C:\Users\你的用户名 | 个人目录，桌面、文档、下载均位于此处 | 这是日常需要管理的位置 |
