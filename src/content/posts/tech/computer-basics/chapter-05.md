**本章要点**

- 能使用任务栏与虚拟桌面组织当前任务。

## 5.1 桌面与任务栏

开机后进入的画面称为桌面。桌面实际上是一个文件夹，放在桌面上的文件都存放在 C 盘并占用 C 盘空间。桌面适合临时存放待处理的文件，长期保存的个人文件应放在数据盘。

屏幕最下方的横条称为任务栏。左端是 Windows 徽标，单击可打开开始菜单；中部显示正在运行的程序；右端是通知区，显示时间、音量、网络以及后台程序的图标。

开始菜单里可以直接搜索程序与文件，中部是固定的常用程序与最近使用的内容，左下角是账户与电源按钮。按 Win 键打开，再按一次关闭。

固定常用程序到任务栏的方法：右键单击任务栏上的图标，选择「固定到任务栏」。此后即使程序未运行，图标仍保留在任务栏，单击即可启动。浏览器、文件管理器、微信都适合固定。

Win+数字键 1 到 9 可快速启动任务栏上第 n 个程序。固定五个常用程序后，这五个组合键即成为五条快捷入口。按住 Shift 再按数字键，则以新窗口启动该程序。

任务栏右端的一小块区域称为通知区。程序关闭窗口后仍在后台运行时，其图标保留在此处。单击小箭头展开，右键单击目标图标并选择退出，程序方真正关闭。通知区还显示音量、网络、电池与输入法状态，单击即可打开对应的快捷设置。

## 5.2 显示设置与虚拟桌面

桌面图标出现问题时，解决办法都在右键菜单的「查看」中。

**表 5-1　桌面图标常见问题**

| 现象 | 解决办法 |
|---|---|
| 图标无法拖动 | 右键单击桌面 → 查看，取消勾选「自动排列图标」 |
| 图标排列不整齐 | 右键单击桌面 → 查看，勾选「将图标与网格对齐」 |
| 图标全部消失 | 右键单击桌面 → 查看，勾选「显示桌面图标」 |
| 图标过小不易辨识 | 右键单击桌面 → 显示设置，将缩放调整为 125% 或更高 |

笔记本屏幕分辨率高而尺寸小，采用默认 100% 缩放时文字偏小。调整为 125% 后观感明显改善，代价是屏幕可显示的内容减少。

分辨率决定同屏可显示的内容数量。分辨率越高画面越细腻，但文字越小，因此需要与缩放比例配合设置。1920×1080 通常配 100% 缩放，2560×1600 一类高分辨率屏幕建议配 150%。

虚拟桌面可在同一块屏幕上建立多个相互独立的桌面环境。按 Win+Ctrl+D 新建桌面，按 Win+Ctrl+左右方向键切换。桌面 1 上的窗口不会出现在桌面 2 上，切换时两边的窗口均保持在原位置。将学习与娱乐分置于不同桌面，查找窗口的效率明显高于在大量窗口中翻找。

**表 5-2　虚拟桌面快捷键**

| 快捷键 | 作用 |
|---|---|
| Win+Tab | 任务视图，查看所有窗口和虚拟桌面 |
| Win+Ctrl+D | 新建虚拟桌面 |
| Win+Ctrl+左右方向键 | 切换到左右虚拟桌面 |
| Win+Ctrl+F4 | 关闭当前虚拟桌面 |

## 5.3 截图与录屏

截图是使用频率最高的操作之一。

**表 5-3　四种截图方法对比**

| 方法 | 操作 | 结果 |
|---|---|---|
| 截图工具 | Win+Shift+S | 框选任意区域。两种系统均复制到剪贴板；Windows 11 同时自动保存为文件，Windows 10 需通过右下角通知保存 |
| 全屏截图 | Windows 10 按 Print Screen | 将整个屏幕复制到剪贴板。Windows 11 默认改为弹出区域截图，如需恢复原有行为，应在「设置」→「蓝牙和其他设备」→「键盘」中关闭「使用 Print Screen 键打开屏幕截图」 |
| 全屏存文件 | Win+Print Screen | 直接保存成文件 |
| 聊天工具截图 | 微信 Alt+A | 需微信处于运行状态，可直接标注 |

截图的保存位置如下：打开「此电脑」，进入「图片」，其中的「屏幕截图」文件夹即截图存放处。录屏的保存位置不同：用截图工具录的，在「视频」下的「屏幕录制」文件夹；用 Xbox Game Bar 录的，在「视频」下的「捕获」文件夹。若这些子文件夹不存在，文件会直接落在「视频」根目录下。

如需直接在聊天窗口中发送，不必前往文件夹查找：截图后将光标置于聊天输入框，按 Ctrl+V 即可粘贴。因此截图后不应立即复制其他内容，否则剪贴板内容会被覆盖。

按下 Win+Shift+S 后，屏幕上方会弹出一排按钮，可选择矩形、任意形状、窗口或全屏。截图工具支持延迟截图，在工具栏上选择延迟秒数，用于捕捉按下即消失的菜单。

录屏使用 Win+Shift+R，这是 Windows 11 截图工具自带的功能，框选区域后即开始录制，结束后可直接保存为 MP4。Windows 10 不支持该功能，替代方案是 Xbox Game Bar：按 Win+G 打开，按 Win+Alt+R 开始和停止录制。
