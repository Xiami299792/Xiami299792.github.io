## 关于技术

这个站是这么搭起来的：

- **Astro** —— 静态站点生成器，构建产物就是纯 HTML，没有后端
- **Markdown** 写作，文章即文件，全部存在 Git 仓库里
- **GitHub Pages** 托管，**GitHub Actions** 推送即部署
- **Pagefind** 做全文搜索，索引在构建时生成
- **Giscus** 做评论，挂在 GitHub Discussions 上
- 西文字体自托管，中文字形交给系统字体

没有数据库，没有服务器，没有任何追踪脚本。
