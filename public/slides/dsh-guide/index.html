为什么有这本书

它不是教你用 AI

是让 AI 按你的方式干活

  • 01你已经解释过第三遍的要求，它应该记住
  • 02你还没说清楚的事，它应该先问，而不是先写
  • 03它交出来的东西，应该有人能验收

这三句话，就是全书的主线。

第 1 章 · 三个名词

你出模型，它出工作台

harness+model=agent
模型

你要接进去的那个大脑。买或接，都归你管。

harness

DSH 这个工作台。它负责把大脑接到你的文件和工具上。

Agent

跑起来的那个家伙。你真正对话的对象。

第 1 章 · 1.1 到 1.3

名词不通，后面全是黑话

名词一句话你要管什么
DSH跑在你电脑上的 AI 工作台装好、配好、给它工作区
API 与 Key模型按调用量计费，Key 就是你的账户凭证别外传，别写进代码
Agent模型加工具加记忆，能自己连续干活给它目标，也给它边界

第 1 章还剩十一个常用词，在那章末尾。

第 2 章 · 安装

装到能说上第一句话

  1. 装 DSH按系统选安装包，装完能打开界面
  2. 拿到 Key去模型服务商注册，复制那一长串字符
  3. 填进去第一次打开会引导你填，填完就能对话
  4. 验收让它读一个文件并总结，读对了就算通

卡住了先翻 2.4 的故障索引，别对着屏幕硬试。

第 3 章 · 首次配置

配置只做一次，但选错了会难受很久

填 Key，选模型

便宜的模型适合改错别字，贵的留给要想的问题。先各试一次，你就有感觉了。

选工作区

它默认只能看见你给它的那个文件夹。工作区选错，它就会找不到文件。

关掉不需要的

默认开着的功能不一定都要。全开只会让它更爱自作主张。

知道配置文件在哪

3.6 那一节点明了路径，出问题时你就知道去哪儿看。

第 3 章 · 3.4

先说把权限收住这件事

它能在你电脑上读写文件。这不是小事。

最紧只读

先让它读，别让它删。第一次上手就该这样。

中间可写工作区

只在你指定的文件夹里动手，日常够用。

最松全盘

除非你非常清楚自己在做什么，否则别开。

先收住，需要时再开。反过来很容易出事。

第 4 章 · Skill

你已经解释过第三遍了

那就该写个技能

你的情况用什么
这件事只做这一次直接跟它说
反复做，要求基本固定写技能
需要新能力、新界面、新接口装插件

技能是说明书，插件是零件。一个是方法，一个是能力。

第 4 章 · 4.3

技能写完了没人用，多半栽在 description

没人用的写法

整理我的资料

只说了做什么，没说什么时候该用它。

会被用上的写法

当用户丢来一堆零散笔记、要求整理成一篇有结构的文章时使用

写清了触发场景，它才知道该在什么时候拿出来。

description 不是简介，是触发条件。

第 4 章 · 4.7

现成的技能，让 Agent 自己装

  1. 先看 SKILL.md它会读你的文件，装之前值得花两分钟看清楚
  2. 说一句话帮我安装这个 skill：<仓库地址>
  3. 确认装上了问它现在有哪些技能，列表里能看到就算成

第 5 章 · 评审团

为什么不能让 AI 自己检查自己

因为它会给自己打高分

  • 01换一个上下文，它就记不住自己刚写过什么
  • 02每人只盯一件事，别让三个人说同样的话
  • 03要求它给出证据，而不是感觉

用子代理，才是真的互相看不见。同一段上下文里的评审，都是客气。

第 7 章 · 使用之外

三件没人一开始就告诉你的事

卡住了怎么问

贴完整报错，说清你想干什么、已经试过什么。只说报错，它只能猜。

会话怎么管

一个会话只做一件事。聊得太长，它会把前面忘掉，还会变慢。

花钱怎么控

先看清单价再放量。长文档和反复重试，是账单涨得最快的两个地方。
